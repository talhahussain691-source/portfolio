# Mohammad Talha Hussain — Portfolio

Graphic designer · web designer · social media manager.

**Live site:** https://talhahussain691-source.github.io/portfolio/

A one-page portfolio built like a design workspace. Every time the site opens, a team of
cursors "builds" the page in front of you: guides are dragged in, frames are drawn,
images are dropped and duplicated, and headings are typed small and resized. At the end
the camera glides back to the hero.

## Editing content

All project lists live near the top of the `<script>` in `index.html`:
`MARKS`, `MOCKUPS`, `CARDS`, `CASES`, `BROCHURES`, `BOARDS`, `APLUS`, `SITES`,
`POSTERS`, `REELS`, `REVEALS`. Add or remove a file path to change what shows.
Colours and fonts are set in the `:root` block at the top of the `<style>`.

## Build animation

- Plays on every visit (skipped for links that jump to a section, e.g. `#contact`,
  and for visitors with "reduce motion" turned on).
- Skip: **Skip build** button, Esc, mouse wheel or touch.
- Watch again: the **Story mode** button in the hero, the footer link, the red ▶ in
  the toolbar, or press **R**.
- URL options: `?build=slow`, `?build=fast`, `?speed=0.7`, `?cam=700`, `&agents=24`.

## Design tools on the page

Toolbar (appears when you scroll): **V** move · **P** pen (draw on the page) ·
**I** eyedropper · **G** layout grid and rulers. The Layers panel on the right jumps
to any chapter.
